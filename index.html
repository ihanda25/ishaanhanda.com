BriefCase

Built through Purdue University. Fine-tuned DistilBERT and Legal-BERT on CUAD (13,000+ annotated legal clauses) using chain-of-thought rationales distilled from Llama 3.1 8B, reaching 0.89 macro F1 on a 10-class contract risk classification task. Machine Learning · Semantic Search

MovieSearch

A semantic movie search engine for finding a film from a description you remember. Encodes queries and a catalog of 826 Disney, Pixar, Marvel, and Lucasfilm movies — built from public TMDB metadata — with a local sentence-transformer model, then ranks the top five results using cosine similarity over 384-dimensional embeddings. Built with NumPy vector retrieval and a Flask API; ongoing work focuses on improving scene-level retrieval beyond short plot summaries.
